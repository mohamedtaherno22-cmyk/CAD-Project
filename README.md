# CAD-Project

The project is a miniature CAD Model of the wooden roller coaster inspired by a coaster in RollerCoaster Tycoon 2 called Timber Topper. The model consists of multiple parts, which can be used to create other designs of the same coaster, which means that the track is fully customizable. 

The project was done in Fusion 360,
